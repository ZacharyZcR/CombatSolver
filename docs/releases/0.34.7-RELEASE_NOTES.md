# CombatSolver 0.34.7 试玩版

## 简体中文

- 全自动受收益限制暂停时显示原因和预测数值，开启前检查已有路线，避免按钮刚开又关。
- 成长与净收益目标默认保留 30 HP，累计战损上限仍为 10 HP。已有自定义设置保留；平衡模式不使用这些限制，界面增加说明。
- 商店评分平滑计算留钱成本，消除金币从 149 到 150 时的评分跳变。

## English

- Full auto explains reward-limit pauses with predicted values and checks existing routes before enabling.
- Growth and Net Resources default to retaining 30 HP with a 10 HP total-loss cap. Existing custom settings are preserved. The UI clarifies that these limits do not apply to Balanced mode.
- Shop scores apply reserve costs continuously, eliminating the score jump between 149 and 150 gold.
