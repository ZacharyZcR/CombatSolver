# 0.35.1-enhanced.1 增强试玩

## 简体中文

- 整合上游 0.35.1 的战斗修复、搜索性能、内存回收和战斗瞬间执行改进。
- 保留增强分支的奖励与商店评分、流派选择、成长与净收益目标、药水策略及缓存改进。
- 在线战绩统计默认关闭，可在设置中主动开启；已有明确设置保留。
- 此包为个人增强版，与上游同号版本不同。抓牌机制理解未在本次重新调整；游戏内搜索、部署和界面仍待验证。

## English

- Integrates upstream 0.35.1 combat fixes, search performance, memory reclamation and instant combat improvements.
- Retains enhanced reward/shop advice, archetype selection, growth/resource objectives, potion policy and cache improvements.
- Online statistics default to off; users can enable them in settings. Existing explicit preferences are retained.
- This personal enhanced build differs from upstream. Draft heuristics were not retuned in this update; in-game search, deployment and UI validation remain pending.
