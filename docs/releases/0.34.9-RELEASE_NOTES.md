# CombatSolver 0.34.9 试玩版

## 简体中文

- 永久成长默认目标 3 点，净收益默认目标 25 分；均可调整，0 使用默认值。达标、完整获胜且满足血量限制后结束继续探索。
- 路线摘要显示永久成长与资源增量，详情列出净收益计分构成及血量情况；均为预测值。
- 减少手牌估值、预测状态重映射和预测洗牌中的重复工作与临时分配。完整战斗的性能提升仍待实测。

## English

- Growth defaults to 3 points and Net Resources to 25. Both targets are configurable; zero uses the default. Search finishes after reaching the target with a complete victory within HP limits.
- Route summaries show projected growth and resource gains; details include the net-score breakdown and HP outcomes.
- Reduces repeated work and temporary allocations in hand valuation, prediction-state remapping and projected shuffles. Whole-combat performance remains to be measured.
