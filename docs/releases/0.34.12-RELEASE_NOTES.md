# 0.34.12 抓牌流派权重 / Archetype-aware card advice

- 手动选择流派后，奖励和商店更优先补齐核心组件及供需缺口。
- 缺少前置的收益牌与同名重复组件降低加权，保留通用补防、过牌与金币限制。
- 评分详情单独显示流派贡献，已包含在配合分内。

- Selected archetypes now give stronger reward/shop priority to core components and missing resource/payoff links.
- Unsupported payoffs and duplicate copies receive smaller bonuses; defense, draw needs and affordability still apply.
- Score details show the archetype contribution as part of synergy.
